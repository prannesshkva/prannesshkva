### Production Architectures & Engineering Implementations

#### 1. [Ael-Agents](https://github.com/prannesshkva/Ael-Agents) — Biomimetic Multi-Agent Cortical Architecture
* **Triple-Network Cortical Hierarchy:** Maps agent reasoning into the Default Mode Network (DMN), Salience Network (SN), and Central Executive Network (CEN).
* **0-Token Routing Engine:** Computes exact PyTorch autograd Jacobian sensitivity ($J_i = |\partial \mathcal{L}_{\text{cortex}} / \partial w_i|$) across domain specialists, gating active memory in $<15\text{ ms}$ on CPU without consuming LLM tokens.
* **Epistemic Surprise Bridging:** Embeds specialist hypotheses in a 768-D manifold (`BAAI/bge-base-en-v1.5`) and isolates cross-domain dissimilarity using a $4 \times 4$ Representational Dissimilarity Matrix (RDM).
* **Working-Memory Bottleneck ($k=2$):** Constrains executive synthesis to the top 2 specialists, cutting context consumption by **93.7%** (~2,200 tokens/run vs. 35,000+ tokens in typical swarms).
* **Offline Dream-RSI:** Implements background memory consolidation cycles that refine weights and verify free-energy reduction ($F_{\text{dream}} < F_{\text{wake}}$).
* **Benchmarks:** Out-of-the-box KRAS-G12D de novo inhibitor design verified via RDKit valence compilation and SciPy RK45 2-compartment PK/PD ODEs (100% steady-state target occupancy); 100% on MedMCQA pharmacology board standards.

#### 2. ISOM (Isometric State Operator Manifold) — Sub-Quadratic Context Engine
* **KV-Cache Bypass:** Projects sequence history onto an isometric manifold, eliminating the quadratic $O(N^2)$ memory wall of standard Transformers.
* **Bounded Memory Footprint:** Enables $100\text{K}$ to $1\text{M}+$ token contexts on consumer GPUs with $O(1)$ state-cache growth.
* **Multi-Scale Implementations:** Scaled across an Edge 130M SSM-MoE prototype, a 1.5B Reasoning Cache Engine, and a 40B Enterprise Engine.

#### 3. QU-SSM (Quasi-Unitary State-Space Models) — Non-Dissipative Sequence Modeling
* **Continuous Lie-Group Transitions:** Constrains recurrent state transitions along $\text{SO}(2)$ and $\text{SO}(16)$ Lie groups, preventing contractive eigenvalue decay and vanishing/exploding gradients.
* **Hardware Acceleration:** Custom CUDA kernels (`qu_ssm_cuda.cu`) providing hardware-level parity and high throughput on GPU runtimes.
* **Long-Range Dynamics:** Maintains constant state norms across ultra-long horizons without requiring periodic normalization resets.

#### 4. SAGUS (State-Aware Graph Unified System) — Monolithic Origin
* **Continuous Graph Representation:** Unified graph-structured dependencies with continuous state-space dynamics, establishing the foundational research that isolated memory dynamics (QU-SSM) and operator projection (ISOM).
