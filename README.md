### Flagship Systems & Implementations

#### 1. [Ael-Agents](https://github.com/prannesshkva/Ael-Agents) — Biomimetic Multi-Agent Cortical Hierarchy
A PyTorch-differentiable multi-agent coordination architecture modeled on the human brain's triple-network cortical hierarchy: Default Mode Network (DMN), Salience Network (SN), and Central Executive Network (CEN), coupled with offline Dream-RSI (Recursive Self-Improvement).
* **0-Token Routing Engine:** Bypasses LLM-as-a-Judge routers entirely. Uses exact PyTorch autograd Jacobian sensitivity ($J_i = |\partial \mathcal{L}_{\text{cortex}} / \partial w_i|$) across specialist weights, gating working memory in $<15\text{ ms}$ on CPU at zero token cost.
* **Epistemic Surprise Bridges:** Maps hypotheses into a 768-D neural semantic manifold (`BAAI/bge-base-en-v1.5`) to construct the $4 \times 4$ Representational Dissimilarity Matrix (RDM), identifying orthogonal reasoning vectors across domain boundaries.
* **Working-Memory Bottleneck ($k=2$):** Enforces human prefrontal capacity, driving a **93.7% token reduction** (~2,200 tokens/run vs. 35,000+ tokens in typical unconstrained swarms).
* **Deterministic Verification:** Validated on de novo KRAS-G12D covalent-reversible inhibitor design via RDKit valence compilation and SciPy RK45 2-compartment PK/PD ODE numerical integration (100% steady-state trough target occupancy, 0 Lipinski violations, QED 0.716); 100% (9/9) on MedMCQA pharmacology board exams.
* **Observability:** Complete production execution verified via [Public LangSmith Trace](https://smith.langchain.com/public/71010a71-b6cf-4e07-b6db-2d3553ad4a3a/r).

#### 2. ISOM (Isometric State Operator Manifold) — Sub-Quadratic Infinite Context
An alternative to standard Transformer KV-cache architectures that eliminates quadratic memory scaling by projecting sequence history onto an isometric state manifold.
* **KV-Cache Bypass:** Projects context into bounded state operators, breaking the GPU memory wall and enabling $100\text{K}$ to $1\text{M}+$ token horizons to execute locally on consumer GPUs.
* **Multi-Scale Deployment:** Architected and benchmarked across three production scales: an Edge 130M SSM-MoE prototype, a 1.5B Reasoning Cache Engine, and a 40B Enterprise Engine.
* **Sub-Quadratic Scaling:** Retains associative recall across long sequences with $O(1)$ state-cache growth.

#### 3. QU-SSM (Quasi-Unitary State-Space Models) — Non-Dissipative Sequence Modeling
A continuous-time state-space architecture resolving the fundamental compromise between numerical stability and long-range memory retention in recurrent models.
* **Lie-Group Unitary Recurrence:** Enforces continuous state transitions along $\text{SO}(2)$ and $\text{SO}(16)$ orthogonal groups, preventing the contractive eigenvalue decay that causes catastrophic forgetting in standard linear SSMs.
* **Gradient Preservation:** Completely eliminates exploding and vanishing gradient dynamics across extended horizons without artificial normalization resets.
* **Custom CUDA Kernel:** Integrated custom CUDA C++ kernel (`qu_ssm_cuda.cu`) providing hardware-native execution and numerical parity with theoretical derivations.

#### 4. SAGUS (State-Aware Graph Unified System) — Monolithic Origin
The foundational unified system that integrated graph topological structures directly into continuous state spaces. SAGUS established the mathematical basis proving that memory preservation (QU-SSM) and sequence caching (ISOM) require orthogonal manifold representations.
